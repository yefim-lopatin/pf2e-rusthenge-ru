# Pathfinder Adventure: Растхендж — русский перевод

Личный модуль локализации для официального `Pathfinder Adventure: Rusthenge`.
Он содержит только русские замены Babele: исходные карты, изображения, музыка,
сцены и документы загружаются из купленного официального модуля.

## Требования

- Foundry VTT 14.365;
- Pathfinder 2e 8.4.0;
- Pathfinder Adventure: Rusthenge 14.1.0;
- Babele 2.9.1;
- `pf2e-ru` 2.2.0;
- `ru-ru`.

## Установка на Molten Hosting

1. Скачайте `pf2e-rusthenge-ru.zip` из приватного GitHub Release.
2. Распакуйте архив. Внутри должна находиться папка `pf2e-rusthenge-ru`.
3. Загрузите папку в `Data/modules` через WebDAV или файловый менеджер Molten.
4. Перезапустите сервер Foundry.
5. Выберите русский язык и активируйте официальный Rusthenge, Babele,
   `pf2e-ru`, `ru-ru` и этот модуль.
6. В Babele включите **Sync imported Adventure token names**.
7. Импортируйте Rusthenge в чистый мир после активации переводов.

Не импортируйте Adventure повторно поверх английской копии в рабочем мире.

## Обновление

Перед обновлением сохраните резервную копию мира. Замените папку модуля новой
версией, перезапустите Foundry и проверьте предупреждение о версии официального
Rusthenge.

## Источники и права

Художественный текст сверен с русским переводом RpgLeshiy. Модуль предназначен
для личного некоммерческого использования и требует законно приобретённый
официальный модуль Rusthenge. PDF и ресурсы Paizo в репозиторий не входят.
